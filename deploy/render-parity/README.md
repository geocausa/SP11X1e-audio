# SP11 Windows render-parity candidate

This candidate consolidates the working SP11 platform and speaker stack under
one unique, rollback-safe kernel/topology identity:

- kernel release: `7.1.5-sp11-render-parity+`;
- GRUB id: `sp11-audio-render-parity`;
- boot bundle: `/boot/sp11-7.1.5-audio-render-parity`;
- modules: `/lib/modules/7.1.5-sp11-render-parity+`;
- sound-card/topology identity:
  `X1E80100-Microsoft-Surface-Pro-11-Render-Parity`.

It combines:

1. the current protected DEFAULT AudioReach graph, CPS/VI feedback and WSA
   high-output policy;
2. the evidence-backed four Windows DEFAULT module-control links, including
   `POPLESS_EQ 0x4664 <-> VOL_CTRL 0x4663` with intent `0x08001118`;
3. the exact Windows final-volume plus four-frame GainStep transaction;
4. the Windows SOFT_PAUSE DSP command implementation;
5. the WSA884x ordinary-clock-stop correction from patch `0046` while keeping
   the UNATTACHED/ATTACHED context-loss restore;
6. the complete known-good Wi-Fi, Phase91 touch, OLED and audio dependency
   closure from the full soft-pause build.

The build deliberately excludes speculative MAX34417 probing, unproven PBR
DP4 scheduling, guessed WaveSpeaker EQ/DRC/Bass Boost stages and an invented
NOTIFICATION selector.

The menu generator does not alter the persistent GRUB default.  Deployment
and one-shot arming remain separate operations.
